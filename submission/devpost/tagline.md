# Tagline

**Break AI agents safely. Replay failures. Prove the fix.**

## Short description (for the Devpost "elevator pitch" field, under 200 characters)

Record a tool-using AI agent, replay it offline, inject production failures, catch unsafe
behaviour with invariants, and prove the fix with a pytest regression.

## One-liners for social posts

- An AI support agent refunded a customer twice. GhostReplay replays it offline, breaks a
  healthy run the same way, and proves the fix with a regression test.
- Same framework, different domain: a stale health check makes an SRE agent terminate a
  healthy fleet. GhostReplay catches it before production does.
